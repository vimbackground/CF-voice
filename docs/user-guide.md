# CF-voice 用户指南

这是一份给普通用户的说明书。你不需要了解 Cloudflare、API 或编程，也可以按本指南使用网页和支持 OpenAI TTS 的客户端。

## 先理解两种“密码”

CF-voice 中可能会看到两类完全不同的密码：

| 你看到的项目 | 用途 | 应该填什么 |
| --- | --- | --- |
| 网页访问密码 | 打开 CF-voice 网页时显示的密码页 | 部署者设置的 `ACCESS_PASSWORD` |
| 客户端的 API Key / 密钥 | 一些 TTS 客户端要求必须填写才能保存设置 | 任意非空占位文本，例如 `cf-voice-local` |

**网页密码不能作为 API Key 使用，也不需要填入客户端。** 当前版本的网页密码只保护浏览器网页；语音 API（`/v1/*`）不会检查它。客户端中的 API Key 输入框通常只是该客户端的必填项，CF-voice 不会读取、保存或验证其中的占位文本。

> 如果你不是部署者，只需向部署者索要网页密码。不要把自己的第三方平台密钥或聊天平台密钥填进 CF-voice 客户端设置。

## 场景一：直接在网页生成语音

这是最简单、最适合首次使用的方法。

1. 打开部署者给你的 CF-voice 网址。
2. 若出现密码页，输入部署者提供的网页访问密码。
3. 保持在“文字转语音”页，输入一段文字。
4. 选择音色、语速、音调和风格；不确定时先点击“试听当前音色”。
5. 点击“开始生成语音”，播放满意后下载文件。

常见注意事项：

- 网页密码只用于打开网页，不要发到公开群组或截图中。
- 长文章建议分段生成。这样出错时更容易重试，也更便于试听与修改。
- 如果某种风格听起来不自然，换成“通用风格”或换一个音色再试；不同音色支持的表达风格并不完全相同。

### 选择小技巧

- **不知道选哪个**：中文先用 `zh-CN-XiaoxiaoNeural`，男声先用 `zh-CN-YunxiNeural`；英文先用 `nova`。
- **正式公告或新闻**：优先试晓甄、云泽，并使用“新闻播报”或“严肃正式”风格。
- **短视频和活动**：优先试晓双、云扬、云夏，并使用“愉快欢乐”风格。
- **课程与知识讲解**：优先试晓辰、晓睿、云健；语速从“正常”开始。
- **长文或睡前内容**：优先试晓悠、晓颜、云枫，并将语速调为“慢速”或“正常”。

## 场景二：在支持 OpenAI TTS 的客户端中使用

许多桌面工具、终端工具或自动化软件都提供“OpenAI TTS”“OpenAI Compatible”或“自定义 API”设置。下面以“让客户端把回复朗读出来”为例。

### 需要准备的信息

假设你的 CF-voice 网址是：

```text
https://voice.example.workers.dev
```

请在客户端中填写：

| 客户端字段 | 填写内容 |
| --- | --- |
| 服务类型 | OpenAI TTS / OpenAI Compatible |
| Base URL / API 地址 | `https://voice.example.workers.dev/v1` |
| API Key / 密钥 / Password | 任意非空占位值，例如 `cf-voice-local` |
| 模型 | `tts-1` |
| 音色 | `zh-CN-XiaoxiaoNeural`；也可先试 `nova`、`alloy` 等常见名称 |

有些客户端会自动在 Base URL 后补上 `/v1`，有些不会：

- 若界面明确写着“Base URL”，通常填 `https://voice.example.workers.dev/v1`。
- 若界面已经固定显示 `/v1` 或要求完整的“Speech Endpoint”，按提示避免重复填写 `/v1`。完整 TTS 地址是 `https://voice.example.workers.dev/v1/audio/speech`。

保存后，用客户端的“测试”“试听”或“发送一段短文字”功能验证。成功时会返回音频，而不是聊天文字。

### API Key / 密码提示怎么处理

- 客户端要求填写 API Key：填 `cf-voice-local` 即可。该值只是让客户端通过自身的表单校验。
- 客户端要求填写 Password：同样填任意非空占位值，**不要填网页访问密码**。
- 客户端支持留空：可以留空。
- 出现“401 Unauthorized”：先确认地址是否为自己的 CF-voice 地址。如果正在使用的是第三方 OpenAI 或 STT 服务地址，则该服务的密钥规则与 CF-voice 无关，应向对应服务商查询。

## 场景三：把录音转成文字

1. 在网页切换到“语音转文字”。
2. 上传音频文件，单个文件不超过 10MB。
3. 在“STT 服务设置”选择部署者提供的服务；不确定时先选“硅基流动”。
4. 如果部署者没有配置默认密钥，输入**你自己该 STT 服务的 API Key**。
5. 转录完成后，复制、编辑，或点击“转为语音”。

注意：这里填写的 API Key 是你选定的**语音转文字服务**的密钥，与网页访问密码、客户端占位 API Key 都不同。除非你信任当前部署者，否则不要在公开或他人维护的 CF-voice 网页中输入自己的付费服务密钥。

## 常见问题

### 我有网页密码，为什么客户端仍让我填 API Key？

这是客户端自身的表单要求，和网页密码没有关系。填一个非空占位文本即可。

### 我填了网页密码，客户端为什么不能连接？

CF-voice 的网页密码不是 API 认证凭据。请将客户端 API Key 改为任意非空占位值，并检查 Base URL 是否指向 `/v1`。

### 网页能打开，客户端却显示“找不到接口”或 404？

通常是地址末尾重复或遗漏了 `/v1`。确认完整语音地址最终为：

```text
https://你的域名/v1/audio/speech
```

### 我需要真正限制谁能调用 API，怎么办？

当前的网页密码不能限制 API 调用，也不适合保护付费额度。请让部署者使用 Cloudflare Access、WAF、API Gateway 或在 Worker 中增加专用 API Key 校验。启用这类保护后，客户端需要按部署者提供的方式附带认证信息；这属于部署者配置，普通用户无需自行尝试。

## 需要帮助时，发给部署者的信息

不要发送密码和 API Key。可以发送以下信息以便排查：

- 你使用的客户端名称与版本
- 你填写的 Base URL（请隐藏域名中若有的私密部分）
- 报错全文或截图
- 是网页 TTS、客户端 TTS 还是音频转文字出现问题
- 使用的音频格式、文件大小或输入文字长度
